¿Cuál es el problema?

En la Institución Educativa José Joaquín Flórez Hernández, las citaciones a padres de familia se realizaban manualmente mediante formatos físicos y anotaciones. Esto ocasionaba desorganización de la información, dificultades de comunicación y problemas para hacer seguimiento a las citas e inasistencias.

¿Por qué nació EDUTURNOS?

Nació de la necesidad de mejorar y digitalizar el proceso de atención a padres de familia, creando una plataforma que permitiera organizar las citaciones, controlar los horarios, enviar notificaciones y realizar seguimiento desde un solo lugar.

¿Cómo se desarrolló?

El proyecto se desarrolló por etapas:

  1. Identificación de las dificultades del proceso manual.
  2. Diseño de módulos, usuarios y funcionalidades.
  3. Programación de la interfaz, la aplicación y la base de datos.
  4. Integración de los componentes.
  5. Pruebas, corrección de errores y mejoras.

¿Cuál es su estructura?

EDUTURNOS está dividido en seis módulos principales:

  • Administración.
  • Registro y verificación.
  • Autenticación y permisos.
  • Gestión de citaciones.
  • Seguimiento.
  • Reportes.

Cuenta con roles de superadministrador, administrador o coordinador, docente, acudiente, estudiante e invitado.

¿Cómo está programado?

Se utiliza una arquitectura de tres partes:

  • Frontend: HTML, CSS y JavaScript para la interfaz.
  • Backend: Python y Flask para la lógica y el funcionamiento.
  • Base de datos: MySQL para almacenar y organizar la información.

También se utiliza Git y GitHub para guardar el código y trabajar en equipo.

Conclusión

EDUTURNOS es una solución tecnológica que busca reemplazar los procesos manuales de citación por un sistema digital, facilitando la organización, la comunicación y el seguimiento institucional. Además, permitió aplicar nuestros conocimientos de programación y desarrollar un proyecto en equipo.
