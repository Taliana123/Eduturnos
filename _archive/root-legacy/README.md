# Material heredado de la raíz

Esta carpeta conserva artefactos de una versión anterior de EDUTURNOS que ya no forma parte de la aplicación Flask activa.

- `paginas-html/`: páginas HTML estáticas/prototipos. Sus enlaces relativos se mantienen entre ellas.
- `TODO_EL_CODIGO.txt`: volcado histórico de código y páginas del proyecto anterior.

La aplicación actual usa `templates/`, `routes/` y `static/`. Los puntos de entrada vigentes (`README.md` y `LANZAMIENTO.md`) permanecen en la raíz.
