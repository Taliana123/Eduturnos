# DOCUMENTACIÓN - EDUTURNOS

## 1. Nombre del proyecto

EDUTURNOS

## 2. Descripción

EDUTURNOS es un sistema diseñado para gestionar y organizar las citaciones entre docentes, coordinadores y padres de familia de una institución educativa.

El sistema permite registrar, consultar y controlar las citas, evitando duplicaciones y facilitando el seguimiento de cada citación.

## 3. Objetivo

Desarrollar un sistema que permita administrar de manera organizada las citaciones escolares, facilitando la comunicación entre la institución educativa y los padres de familia.

## 4. Usuarios del sistema

El sistema contempla los siguientes tipos de usuarios:

- Administrador
- Docente
- Coordinador
- Padre de familia
- Rector
- Orientador escolar
- Personal administrativo

## 5. Funcionalidades principales

- Registrar usuarios.
- Gestionar estudiantes.
- Registrar acudientes.
- Registrar docentes.
- Crear y administrar citas.
- Registrar motivos de las citas.
- Controlar estados de las citas.
- Enviar notificaciones.
- Evitar citas duplicadas.
- Consultar información del sistema.

## 6. Tecnologías utilizadas

- Visual Studio Code
- HTML
- CSS
- MySQL
- Git
- GitHub

## 7. Estructura del proyecto

El proyecto EDUTURNOS está organizado en diferentes carpetas para facilitar su desarrollo y mantenimiento.

Entre ellas se encuentran:

- `css/` para los estilos.
- `sql/` para los archivos de base de datos.
- `docs/` para la documentación del proyecto.
