# DÍA 4 — REGLAS DEL MÓDULO DE CITACIONES

## Objetivo

Definir las reglas de negocio necesarias para controlar la creación y administración de las citaciones.

## Reglas

1. Una citación debe estar relacionada con un estudiante existente.
2. El acudiente debe estar relacionado con el estudiante.
3. El docente debe tener permisos para generar la citación.
4. La fecha debe ser válida.
5. La hora debe estar disponible.
6. No se deben generar citaciones incompatibles para el mismo horario.
7. Toda citación debe tener un motivo.
8. Una citación cancelada debe permanecer registrada.
9. Las modificaciones importantes deben quedar en el seguimiento.
10. Las citaciones deben conservar su historial.

## Estados

* Pendiente
* Confirmada
* Realizada
* Cancelada
* Reprogramada
* No asistió
* Justificada
