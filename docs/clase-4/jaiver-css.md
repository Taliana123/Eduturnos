## Descripción del trabajo

Durante el Día 4, me encargué de agregar estilos CSS relacionados con la presentación de las citaciones del sistema EDUTURNOS.

Se agregaron estilos para la tabla de citas, definiendo su ancho, separación de bordes, espaciado interno y alineación del contenido.

También se agregaron estilos para los estados de las citaciones, incluyendo los estados pendiente, confirmada, realizada y cancelada.

## Trabajo realizado

* Estilos para `.tabla-citas`.
* Estilos para los encabezados y celdas de la tabla.
* Estilos para `.estado`.
* Estilo para el estado pendiente.
* Estilo para el estado confirmada.
* Estilo para el estado realizada.
* Estilo para el estado cancelada.
