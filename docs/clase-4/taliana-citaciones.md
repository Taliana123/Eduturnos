# DÍA 4 — MÓDULO DE CITACIONES

## Responsable

Taliana

## Actividad

Desarrollo de las interfaces correspondientes al módulo de citaciones de EDUTURNOS.

## Descripción del trabajo

Durante el Día 4, me encargué de crear los archivos correspondientes al módulo de citaciones del sistema EDUTURNOS.

Se creó la interfaz `crear-citacion.html`, destinada al registro de una nueva citación. Esta interfaz contiene campos para ingresar la información del estudiante, acudiente, docente responsable, motivo, fecha, hora, lugar y observaciones.

También se crearon los archivos correspondientes a las diferentes vistas del módulo:

* `citaciones.html`
* `crear-citacion.html`
* `detalle-citacion.html`
* `editar-citacion.html`
* `js/citaciones.js`

La interfaz de creación de citaciones utiliza un formulario HTML mediante el método `POST` y está preparada para enviar la información al archivo `api/crear_cita.php`.
