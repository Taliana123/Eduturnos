# REGLAS DE NEGOCIO - EDUTURNOS

1. Los usuarios deben iniciar sesión.

2. Cada usuario tendrá un rol.

3. Los permisos dependerán del rol.

4. No se permitirán citas duplicadas.

5. Se debe comprobar la disponibilidad del horario.

6. Los datos obligatorios deben estar completos.

7. Las citas tendrán un estado.

8. Las acciones dependerán de los permisos.
