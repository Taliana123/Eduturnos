# CLASE 1 - INTERFAZ DE USUARIO

## Integrante

Taliana

## Área

Capa de presentación

## Trabajo realizado

Se desarrolló la estructura inicial de la interfaz de usuario del sistema EDUTURNOS, enfocada en la pantalla de inicio de sesión.

## Interfaz desarrollada

* Pantalla de inicio de sesión.
* Título del sistema EDUTURNOS.
* Campo para ingresar el usuario.
* Campo para ingresar la contraseña.
* Botón "Ingresar".
* Estructura HTML básica de la interfaz.
* Vinculación de la hoja de estilos `css/estilos.css`.

## Resultado

Se creó la estructura inicial de la pantalla de inicio de sesión de EDUTURNOS, permitiendo visualizar los campos de usuario y contraseña y el botón de ingreso.

## Evidencia

El código HTML de la página principal contiene la estructura de la pantalla de inicio de sesión y sus elementos principales: usuario, contraseña y botón de ingreso.
