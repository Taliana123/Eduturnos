## Actividad

Desarrollo de archivos PHP para gestionar el seguimiento, confirmación, reprogramación y notificaciones de las citaciones de EDUTURNOS.

## Descripción del trabajo

Durante el Día 5, me encargué de crear los archivos correspondientes al backend del módulo de seguimiento y notificaciones de EDUTURNOS.

Se creó el archivo `confirmar_cita.php`, encargado de procesar la confirmación de una citación y actualizar su estado en la base de datos.

También se crearon los archivos `reprogramar_cita.php`, `seguimiento.php` y `notificaciones.php`, correspondientes a las funcionalidades de reprogramación, seguimiento y notificaciones del sistema.

Los archivos fueron organizados dentro de la carpeta `api`, manteniendo la estructura del proyecto y utilizando la conexión existente con la base de datos.

## Archivos creados

* `api/confirmar_cita.php`
* `api/reprogramar_cita.php`
* `api/seguimiento.php`
* `api/notificaciones.php`

## Resultado

Se creó la estructura inicial del backend para el módulo de seguimiento y notificaciones de EDUTURNOS, incluyendo el procesamiento de confirmación de citaciones.
