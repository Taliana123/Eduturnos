# DÍA 5 — SEGUIMIENTO Y NOTIFICACIONES

## Responsable

Taliana

## Actividad

Desarrollo de las interfaces correspondientes al seguimiento y las notificaciones de las citaciones de EDUTURNOS.

## Descripción del trabajo

Durante el Día 5, me encargué de crear las interfaces relacionadas con el seguimiento de las citaciones y las notificaciones del sistema EDUTURNOS.

Se creó la página `seguimiento.html`, donde se muestra el proceso de una citación mediante diferentes estados: Creada, Pendiente, Confirmada y Realizada.

La interfaz permite visualizar de manera organizada el avance de una citación y conocer en qué estado se encuentra dentro del proceso.

También se creó el archivo `notificaciones.html`, correspondiente a la interfaz destinada a las notificaciones del sistema.

## Archivos creados

* `seguimiento.html`
* `notificaciones.html`
* `docs/clase-5/taliana-seguimiento.md`

## Resultado

Se creó la estructura inicial de las interfaces de seguimiento y notificaciones de EDUTURNOS, dejando preparada la parte visual para continuar con la integración de estas funcionalidades.
