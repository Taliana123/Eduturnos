# DÍA 6 — REPORTES

## Responsable

Taliana

## Actividad

Desarrollo de la interfaz para la consulta de reportes de EDUTURNOS.

## Descripción del trabajo

Durante el Día 6, me encargué de desarrollar la interfaz correspondiente al módulo de reportes del sistema EDUTURNOS.

Se creó la página `reportes.html`, donde se pueden establecer filtros para consultar las citaciones registradas en el sistema.

La interfaz permite seleccionar una fecha inicial, una fecha final y el estado de la citación. También se agregó un botón para consultar el reporte.

El formulario fue preparado para enviar los filtros mediante el método `GET` al archivo `api/reportes.php`, permitiendo posteriormente integrar la interfaz con el backend.

## Archivo creado

`reportes.html`

## Resultado

Se desarrolló la interfaz inicial del módulo de reportes de EDUTURNOS, dejando preparados los filtros de fecha y estado para su integración con el backend del sistema.
