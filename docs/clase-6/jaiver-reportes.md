# DÍA 6 — ESTILOS DE REPORTES

## Responsable

Jaiver

## Actividad

Diseño de los estilos CSS correspondientes al módulo de reportes de EDUTURNOS.

## Descripción del trabajo

Durante el Día 6, me encargué de agregar los estilos CSS necesarios para la presentación del módulo de reportes del sistema EDUTURNOS.

Se crearon estilos para organizar las tarjetas de información de los reportes, utilizando un diseño adaptable que permite distribuir los elementos de acuerdo con el tamaño de la pantalla.

También se configuraron características visuales como el espaciado, el fondo, los bordes redondeados, la alineación del contenido y las sombras de las tarjetas.

Estos estilos dejan preparada la presentación visual para integrar posteriormente los filtros, la tabla de resultados y el botón de impresión.

## Trabajo realizado

* Creación de estilos para las tarjetas de reportes.
* Organización de las tarjetas mediante CSS Grid.
* Configuración de espacios entre elementos.
* Diseño adaptable a diferentes tamaños de pantalla.
* Configuración del fondo de las tarjetas.
* Bordes redondeados.
* Alineación del contenido.
* Aplicación de sombras.

`css/estilos.css`

## Resultado

Se prepararon los estilos visuales del módulo de reportes de EDUTURNOS, dejando organizada la estructura para integrar las tarjetas, filtros, tabla de resultados y botón de impresión.
