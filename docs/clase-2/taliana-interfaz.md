# CLASE 2 – INTERFAZ EDUTURNOS

## Responsable
Taliana

## Actividad
Desarrollo de la estructura visual inicial del sistema EDUTURNOS.

## Descripción

Durante el Día 2 se desarrolló la estructura visual del Dashboard de EDUTURNOS, preparando la interfaz para que posteriormente pueda integrarse con PHP y la base de datos.

## Trabajo realizado

Se implementaron los siguientes elementos:

- Encabezado principal de EDUTURNOS.
- Menú lateral de navegación.
- Dashboard principal.
- Área de contenido.
- Tarjetas de estadísticas.
- Menú de usuario.
- Botón para cerrar sesión.
- Sección de próximas citaciones.
- Estructura preparada para los diferentes roles del sistema.
- Archivo JavaScript para funcionalidades iniciales.
- Diseño preparado para adaptarse posteriormente a diferentes tamaños de pantalla.

## Dashboard

El Dashboard contiene las siguientes estadísticas:

- Citas de hoy.
- Citas pendientes.
- Citas confirmadas.
- Citas realizadas.

También incluye una sección para mostrar las próximas citaciones registradas.
