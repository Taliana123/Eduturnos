# Inicio sencillo

## Primera vez

Haz doble clic en `PRIMERA_VEZ.bat`. El instalador crea el entorno virtual e instala dependencias.

## Uso diario

Haz doble clic en `ABRIR_EDUTURNOS.vbs`.

No ejecutes `pip install` cada vez que abras el sitio.

## Base local

MySQL Server debe estar instalado y activo. El iniciador intenta arrancar el servicio MySQL automáticamente si existe.

## Modo alternativo

Con Docker Desktop instalado puedes usar `tools/iniciar_docker_local.bat` para levantar EDUTURNOS y MySQL en contenedores.
