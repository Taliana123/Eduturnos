# LANZAMIENTO EDUTURNOS

Esta guía resume el estado de lanzamiento. La aplicación está preparada para desplegarse con Flask/Waitress, Docker, MySQL central, HTTPS y SMTP.

Antes de publicar se deben configurar el servidor, la base de datos de producción, `SECRET_KEY`, dominio/DNS, HTTPS, SMTP y backups; después ejecutar las pruebas extremo a extremo.
